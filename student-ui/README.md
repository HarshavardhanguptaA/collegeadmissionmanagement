# React frontend

This Vite + React frontend is part of the College Admission Management System. Use the root-level `README.md` for the complete PostgreSQL, Spring Boot, authentication, and frontend startup instructions.

Quick start (Windows PowerShell):

```powershell
npm ci
npm run dev
```

By default, the frontend calls `http://localhost:8080/api`. Copy `.env.example` to `.env.local` to override `VITE_API_URL`.
